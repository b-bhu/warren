## Liquid Ledger — Privy onboarding

- [Interactive HTML mock](./privy-onboarding-liquid-glass.html)
- [Rendered mobile preview](./privy-onboarding-liquid-glass.png)

### Direction

**Brief:** classy, distinctive, liquid glass.

**Concept:** a single liquid-glass custody seal holds the user's automatically created
Solana and EVM wallets. The interface uses editorial typography and mineral colors to
feel closer to a private investing register than a generic crypto application.

**Signature element:** two wallet records suspended inside one refractive glass lens.

### Starting tokens

| Token | Value | Use |
| --- | --- | --- |
| Deep harbour | `#07131A` | Main background |
| Wet slate | `#122630` | Glass depth |
| Pearl | `#F3F0E8` | Primary text and action |
| Sea glass | `#A9D8C6` | Solana identity accent |
| Ice blue | `#9AC9DA` | EVM identity accent |
| Old gold | `#C8AD82` | Premium detail, used sparingly |

Display typography uses Didot/Bodoni-style serif fallbacks; body copy uses Avenir/SF;
technical labels use SF Mono. The mock respects reduced motion and visible keyboard
focus.

Custody, recovery, export, Terms, and Privacy language in the mock remains provisional
until the Privy configuration and launch policies are approved.
